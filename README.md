## 📂 ディレクトリ構成 (Repository Structure)
このリポジトリには、以下のデータがアーカイブされています。

- `/CAD/` - 機体設計データ（SolidWorks, Fusion360, STEPファイルなど）
- `/Avionics/` - 電装系の回路図（KiCadなど）、PCBデータ
- `/Software/` - フライトコンピューターのソースコード
- `/Simulations/` - OpenRocketファイル、空力解析（CFD）、軌道シミュレーション結果
- `/Flight_Data/` - 実際の打ち上げ時のテレメトリデータ、ログファイル（CSV等）
- `/Documents/` - 開発資料、設計書、安全審査書類、運用・組み立てマニュアル
- `/Media/` - 機体の写真、打ち上げ時の動画リンクなど
